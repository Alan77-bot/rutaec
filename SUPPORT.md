# Soporte de RutaEC

## Introducción

Este documento establece cómo los integrantes del proyecto RutaEC pueden solicitar ayuda, comunicar dificultades y reportar errores durante el desarrollo de la aplicación web de gestión y venta de pasajes interprovinciales.

## Consultas y solicitudes

Las dudas técnicas, solicitudes de ayuda y nuevas tareas deben registrarse mediante **GitHub Issues**, para mantener un seguimiento organizado.

Antes de crear un issue, se recomienda revisar si ya existe una solicitud relacionada.

## Reporte de errores

Cuando se encuentre un error, se debe utilizar la plantilla `error.md` disponible en GitHub.

El reporte debe incluir:

- Descripción del problema.
- Pasos para reproducirlo.
- Resultado esperado y obtenido.
- Evidencias sin información sensible.

## Seguimiento de solicitudes

Cada issue tendrá un responsable asignado. El jefe del equipo coordinará su seguimiento y verificará que las tareas se atiendan de acuerdo con las prioridades establecidas.

Los integrantes deberán actualizar el estado de sus tareas conforme avancen.

## Problemas de seguridad

Los problemas relacionados con contraseñas, credenciales, información personal o vulnerabilidades deben comunicarse de forma privada, siguiendo las indicaciones de `SECURITY.md`.

No deben publicarse datos sensibles en los issues del repositorio.
